# BulBreak 게임 기획 요약

## 게임 화면 UI
- 글자별 테두리는 표시하지 않는다. 상단 체력·타이머 영역, 오른쪽 위 점수·진행 순서 영역, 제약시스템 패널은 각각 검정 배경에 큰 흰색 테두리를 하나씩 표시한다.
- 미로·전투 플레이 영역에는 직사각형 배경을 추가하지 않고 기존 `resources` 이미지를 사용한다.
- 미로는 6×6 고정이며 격자선과 벽 파괴 횟수 숫자를 흰색으로 표시한다. 출발점·출구의 IN·OUT 글자는 표시하지 않는다.
- 플레이 영역 밖의 체력·타이머·점수·진행 순서·제약 정보는 검정색 패널과 글자 배경에 흰색 글자로 표시한다.
- 점수는 오른쪽 위에 표시한다. 점수 산정 규칙은 아직 미정이다.
- 진행 순서는 `미로 → 미로 → 전투`만 표시하며 추가 설명을 붙이지 않는다.
- 미로 위 상태 영역의 왼쪽 2/3은 체력, 오른쪽 1/3은 무행동 타이머 기준과 남은 시간 표시로 사용한다.
- 체력은 오른쪽부터 소진되며, 이펙트 시트 1행 1열은 남은 체력, 1행 2열은 소진 체력에 사용한다.
- 플레이 영역 안의 글자에는 배경을 추가하지 않는다. 플레이 중의 다른 안내는 검정 배경·흰색 글자를 사용하며 일반 글꼴 배경 규칙보다 우선한다.

## 중요한 내용(이 내용은 AI가 수정할 수 없다)
- 이 기획서는 AI가 수정할 수 있지만 작성한 내용 이해하기 전까지 바꿀 수 없으며, 그 내용을 다른 내용으로 바꿀 수 없다.
- 커밋을 해야하거나, 설명해야될 내용이 있을 시 한글로 작성한다.

## 핵심 콘셉트
- **미로 주파, 전투**를 번갈아가며 반복한다.
- 미친듯이 빠른 행동을 유도하는 전투 시스템
- 어떠한 폰트를 띄워야 할때 그 뒤에 검은색 테두리의 하얀색 직사각형을 알파값 0.5정도로 띄운다. 그리고 폰트는 어지간하면 검은색이다.
- 미로는 n x n 형태의 그리드이지만, 벽은 파괴해야 지나갈 수 있고, 통로는 제약없이 이동할 수 있다.
- 반복 플레이를 위해 증강 시스템을 구상하며, 적은 조작키를 고려해 증강은 랜덤 선택 방식으로 한다.
- **[가장 중요함. 모든 시스템은 이 규칙을 따르고 연관된 부분이 있을 시 바로 언급해야함.]이러한 모든 시스템은 미로의 통로, 벽, 입구, 출구는 어떠한 형태로든 반드시 존재해야하며, 전투의 주인공의 실시간 시스템, 적의 행동 '큐' 시스템또한 어떠한 형태로든 반드시 존재해야한다. 이 경우는 어떠한 이유로든 바뀔 수 없다. 또한 게임오버 시스템은 미로 → 전투, 전투 → 미로로 전환하는 동안 발동되지 않는다.(단, 게임오버 시스템 내용은 1개의 제약시스템을 제외한다.) 그 어떠한 경우에도 조작은 방향키로만 가능하게 한다. (조작에 관한 내용은 어떠한 경우에도 바뀔 수 없다.)**

## 미로
- 처음 또는 전투 주파 후 미로로 전환한다.
- 도착점에 도달하면 자동으로 다음 미로 또는 전투로 이동한다.

- 크기는 **6×6**으로 고정한다.
- 플레이 횟수: **기본적으로 6×6 2회**.

- 벽을 향해 이동 시 기본적으로 두 번 누르면 벽을 파괴한다.

- 기본적으로 벽의 갯수는 행 또는 열 기준으로 절반씩 생성된다.
- 시작점과 도착점은 벽을 생성 후 통로에 생성된다.
- 맨 처음 시작점음 왼쪽 위에서 시작하며, 그 다음부터는 도착점이 시작점이 된다.

## 전투
- 미로 주파 후 실시간 전투로 전환한다.

### 임시 전투 구현 — 최신 적용 기준
- 진행은 **미로 → 미로 → 전투 → 미로 → 미로 → 전투**를 반복한다. 두 번째 미로 출구에서 전투로 전환하고 전투 클리어 후 첫 번째 미로부터 다시 시작한다. 체력과 기존 점수는 전환 시 유지하며 전환 구간의 시간을 차감하지 않는다.
- 전투의 **15초 강제 게임오버는 유지**한다. 아래 임시 판정은 이전의 상세 미정 설명보다 우선한다.
- 적이 준비 중이면 **적 바로 위에** `effect_800x400.png` 2행의 해당 방향 화살표를 표시한다. 왼쪽 1열·오른쪽 2열·위 3열·아래 4열이며, 이어질 공격 방향을 예고한다. 공격 중에는 이 예고 화살표를 표시하지 않는다.
- 적의 첫 방향키 입력은 준비, 이후 새 입력마다 즉시 공격 → 다음 방향 준비 순서로 진행한다. 애니메이션 종료를 기다리지 않으며 시간 경과만으로 다음 적 단계가 실행되지 않는다.
- **플레이어 입력 판정은 실시간**으로 처리한다. 적 애니메이션 재생 중에도 키를 새로 눌렀다면 공격·회피 및 타이머 회복을 처리한다. 키를 계속 누르는 자동 반복 입력은 집계하지 않는다.
- 공격 성공은 **왼쪽 → 오른쪽 → 왼쪽 → 오른쪽** 교대 순서로 판정한다. 첫 공격은 왼쪽이며, 올바른 방향을 입력하면 성공 1회를 더하고 다음 방향을 반대로 바꾼다. 같은 방향 반복이나 첫 오른쪽 공격은 실패다. 이는 기존의 같은 방향 반복 성공 임시 기준을 대체한다.
- 공격 순서는 적 방향 큐와 별도로 관리한다. 회피 입력은 다음 공격 방향을 바꾸지 않는다. 적 공격의 패링·회피 판정은 기존대로 적 방향과 입력 방향을 비교한다.
- 주인공 위에 **노란 화살표**로 다음 공격 방향을 표시한다. 오른쪽 공격 후 왼쪽 화살표, 왼쪽 공격 후 오른쪽 화살표이며, 실패 시에는 기존에 요구한 방향을 유지한다. 적 위의 빨간 예고 화살표와 구분한다.
- 공격 순서 실패 또는 적 공격 방어 실패 시 `effect_800x400.png` **1행 2열**을 주인공 근처에 0.4초 표시한다. 주인공은 **0.6초 동안 오른쪽으로 최대 15도 기울었다 원래 각도로 복귀**한다. 경과 시간과 부드러운 보간을 사용하며 새 입력을 막지 않는다. 연속 실패는 해당 반응을 새로 시작한다.
- **가로 공격 피격 표시 예외**: 적의 가로 공격에서 같은 좌우 입력을 반복하여 현재 요구 공격 방향과 반대가 된 경우, **주인공 피격 애니메이션을 생략**한다. 공격 실패 이펙트·기울기·성공 횟수 유지와 실제 방어 실패 시 타이머 차감은 그대로 적용한다. 상하 공격이나 좌우 교대 순서가 맞는 입력의 방어 실패는 기존 피격 표시를 유지한다.
- **패링·공격 실패 동시 발생 시 표시 보정**: 적의 오른쪽 예고에 오른쪽 키를 눌러 패링했지만, 이번 주인공 공격은 왼쪽이어야 하는 경우 공격 성공 횟수와 다음 방향은 유지한다. 패링 상태는 유지하되 잘못된 방향의 공격 모션·공격 이펙트와 피격 모션을 재생하지 않는다. 별도 패링 시트가 없으므로 기본 자세를 사용하고, 공격 순서 실패 이펙트와 기울기는 유지한다. 좌우 반대 경우에도 동일하게 적용한다.
- **상하 피격 체력 감소**: 적의 위·아래 공격 실행 시 같은 방향으로 회피하지 못하면 **체력 1 감소**와 기존 타이머 0.5초 차감을 함께 적용하고 피격 애니메이션을 표시한다. 준비 중 입력이나 정상 회피에서는 체력을 깎지 않는다. 체력이 0이면 즉시 게임오버이며 공격 성공 누적 10회에 동시에 도달해도 클리어로 넘어가지 않는다.
- **공격 실패는 해당 입력의 성공 횟수 증가만 취소**한다. 이미 누적된 성공 횟수를 초기화하거나 차감하지 않는다. 회피 입력도 성공 횟수를 늘리거나 초기화하지 않는다.
- 공격 성공이 **누적 10회**가 되면 전투를 클리어하고 미로로 넘어간다. 성공 횟수는 다음 전투에서 0부터 시작하며 점수와 별도로 관리한다.
- 적 공격이 실행되는 입력에서 좌우 방향을 올바르게 입력하면 플레이어는 **패링** 상태가 된다. 적 방향이 위·아래라면 같은 방향키로 회피한다.
- 적 공격 실행 시 입력 방향이 다르면 방어 실패로 판정한다. 위 가로 공격 표시 예외를 제외하고 **피격 애니메이션(캐릭터 시트 1행 3열 → 4열)**을 표시한다. 남은 타이머를 0.5초 차감하고 **적의 상하 공격에 맞았다면 체력도 1 감소**한다. 준비 중 잘못 입력한 것만으로 피격되지는 않는다.
- 새 입력은 판정과 화면 동작 모두 즉시 반영한다. 기존 동작이 끝나기를 기다리는 표시 대기를 없애고 공격·회피·패링·피격과 이펙트를 즉시 새로 시작한다.
- 이번 임시 구현에는 증강·제약시스템 전용 판정, 새로운 점수 산정은 추가하지 않는다. 미로의 통로·벽·입구·출구, 플레이어 실시간 입력, 적의 방향만 최대 5개 저장하는 FIFO 큐 및 방향키 전용 조작은 유지한다.

### 전투 애니메이션 시간 계획
- **속도 수정 기준**: 미로처럼 빠른 반응을 우선하여 이전의 첫 프레임 최소 0.5초·최대 1초 규칙을 대체한다. 기본 프레임 간격은 미로와 같은 **0.15초**이며, 적 준비·공격과 공격 이펙트는 각각 지정된 두 프레임을 사용한다.
- 게임오버 시스템의 **최대 타이머**에 연동한다. 현재 남은 시간이 줄어들 때마다 애니메이션 속도가 흔들리게 만들지 않는다.
- 계산식은 `프레임당 초 = clamp(0.075 + (최대 타이머 - 1.0) × 0.0375, 0.075, 0.15)`이다. 최대 타이머 3초 → 0.15초, 2초 → 0.1125초, 1초 이하 → 0.075초이다.
- 각 애니메이션을 시작할 때 표시 간격을 확정한다. 빠른 새 입력은 이전 프레임을 중단하고 새 동작을 즉시 표시한다. 최대 타이머 변경은 다음 애니메이션부터 반영한다.
- 애니메이션은 경과 시간(초) 기준으로 처리한다. 재생이 끝난 적 준비·공격은 마지막 프레임을 유지하며 다음 유효 입력을 기다린다. 공격 이펙트는 두 프레임 재생 후 사라진다.
- 주인공의 기존 공격 시트는 기존 배치대로 4프레임이며, 피격·상하 회피는 2프레임이다. 같은 시간 기준을 적용한다.

### 적 방향 큐와 패턴
- 적 패턴은 **`준비 → 공격` 한 종류로 고정**한다. 여러 번 준비한 뒤 연속 공격하는 패턴이나 별도의 대기 단계는 사용하지 않는다.

- 적은 플레이어가 방향키를 새로 누를 때마다 즉시 다음 단계 하나를 실행한다. 첫 입력은 준비이며, 빠른 입력도 적 단계 진행과 플레이어 판정에 모두 반영한다.
- 적의 방향 큐는 **최대 5개를 저장하는 FIFO(선입선출) 큐**이다. 먼저 들어온 방향부터 처리하며, 새 방향은 뒤에 추가한다.
- 큐의 각 원소에는 **방향(왼쪽·오른쪽·위·아래)만** 저장한다. 준비·공격, 시간, 공격 종류 등을 원소에 함께 저장하지 않는다.
- 현재 단계인 `준비` 또는 `공격`은 큐와 별도의 실행 상태로 관리한다. 큐의 5칸은 단계 5개가 아니라 **방향 5개를 담는 공간**이다.
- 준비 시 맨 앞 방향을 확인하고 해당 방향의 화살표를 표시한다. 아직 큐에서 제거하지 않는다.
- 공격 시 준비에서 확인한 같은 방향으로 공격한 뒤 맨 앞 방향을 제거하고, 다음 방향의 준비 단계로 돌아간다.
- 전투 시작 시 방향 5개를 채운다. 공격 완료 후 큐에 방향이 1개 남으면 무작위 방향 4개를 뒤에 추가하여 5개로 채운다. 남은 방향의 순서는 유지한다.
- 큐가 가득 차면 추가 저장하지 않는다. 용량 초과로 맨 앞 방향을 자동 삭제하거나 덮어쓰지 않는다.
- 큐가 비어 있으면 준비·공격을 실행하지 않는다. 방향을 채운 뒤 준비부터 시작한다.

### 플레이어 패링 상태
- 전투에서 왼쪽·오른쪽 방향을 올바르게 입력하면 플레이어는 **`패링` 상태**가 된다.
- 패링은 플레이어의 상태이며, 적의 방향 큐에는 저장하지 않는다. 적의 `준비 → 공격` 고정 패턴과 방향만 최대 5개 저장하는 FIFO 큐 구조는 유지한다.

### 전투 시 적의 패턴
- 고정 순서: `준비(맨 앞 방향) → 공격(같은 방향) → 해당 방향 제거 → 다음 방향 준비`.
- 예: 큐가 `[왼쪽, 위, 오른쪽, 아래, 왼쪽]`이면 첫 입력에 왼쪽 준비, 두 번째 입력에 즉시 왼쪽 공격을 실행한다. 공격 판정 후 큐는 `[위, 오른쪽, 아래, 왼쪽]`이며 세 번째 입력에는 즉시 위쪽 준비를 실행한다.
- 위 방향 큐와 패턴은 임시 전투에 연결했다. 세부 임시 판정과 재생 시간은 위 최신 적용 기준을 따른다.

### 제약 시스템
- 처음 미로 → 전투는 제약시스템이 발동하지 않고, 처음 전투 → 미로에서부터 제약시스템이 발동된다.
- 일반 미로 ↔ 전투 전환 중에는 게임오버가 작동하지 않는다. 단, 제약시스템 동작 중에는 별도의 제약시스템 전용 게임오버가 동작한다. 전환 중 제약 안내는 약 1~2초 보여준다.

## 제약시스템 공통 규칙 — 최신 확정 사항
- 제약시스템이 동작하는 동안에도 게임오버 시스템은 동작한다. 이를 위해 **일반 게임오버 시스템과 별도로 제약시스템 전용 게임오버 시스템을 만든다.**
- 미로 ↔ 전투의 일반 전환 중에는 기존 게임오버 금지 규칙을 유지한다. 단, 전환 중 제약시스템이 동작하는 구간에는 제약시스템 전용 게임오버 판정을 적용한다.
- 전용 게임오버의 구체적인 발생 조건, 타이머·체력 사용 여부는 아직 미정이며 임의로 확정하지 않는다.
- 제약 안내는 아이작처럼 **왼쪽에 제약 관련 그림, 오른쪽에 짧은 설명글**을 배치한다.
- 설명글은 **최대 2줄**, **각 줄은 최대 4문장**으로 제한하고 짧게 작성한다. 자동 줄바꿈을 포함한 실제 표시도 2줄을 넘지 않게 한다.
- 기존 제약 안내 시간 약 1~2초와 방향키 전용 조작을 유지한다. 미로의 통로·벽·입구·출구, 전투 주인공의 실시간 행동과 적의 행동 큐도 유지한다.
- 이 규칙은 기존 문서의 제약시스템 관련 게임오버 금지·예외 설명보다 우선한다. 현재는 기획 반영이며 코드 구현 완료를 뜻하지 않는다.

### 현재까지 구상한 제약 시스템
- 미로 벽 개수 증가
- 전투 : 적 패턴 화살표 금지표시로 전환

## 게임오버
- 최신 기준: 미로는 고정 3초 이내 주파를 기준으로 한다. 입력으로 회복하지 않고 다음 미로에서 3초로 초기화하며 시간 감소 조건은 없다.
- 미로에서 3초가 소진될 때마다 체력 1 감소 후 3초를 다시 센다. 체력 소진 시 게임오버다.
- 전투는 기존 무행동 타이머(입력 시 1초 회복, 최대 시간 제한, 피격 시 0.5초 차감)를 유지한다.
- 이 기준은 아래의 이전 공통 타이머·미로 시간 감소 설명보다 우선한다.

- 게임오버 시스템은 제약 시스템에 따라 바뀔 수 있음.

- 무한으로 강제유지시키는것을 방지를 위해 미로 또는 전투에 진입 시 미로/전투용 타이머를 시작한다. 0부터 15초까지 흐르며 15초가되면 '게임오버' 문구 대신 '관심받고싶음? 옛다 관심' 폰트를 크게 띄우며 게임오버시킨다.(이때, 검은색테두리의 하얀색 직사각형을 폰트 뒤에 띄워서 폰트가 잘 보이게 한다.)

- 기본적으로 '최대시간이 3초인 타이머'를 가진다(이 타이머는 점점 줄어들며 미로 또는 전투로 전환될때마다(전투가 구현이 되어있지 않다면 미로가 바뀔때마다) 약 0.05초정도 감소되며 최종적으로 1초까지 감소한다.). 미로 또는 전투로 전환하는 동안 타이머는 멈추며, 이를 제외하고 키입력이 없을동안 타이머는 줄어든다. 키입력을 하면 기본적으로 1초의 시간이 늘어난다(단, 타이머의 최대 시간 3초를 넘지 않는다, 또한 제약시스템으로 최대 시간이 바뀔 수 있다.). 만약 타이머가 0이 되면 체력이 1 감소된다.

- 첫 번째 기준의 전투 규칙: 무행동 타이머의 감소, 키입력 시 1초 회복, 최대 3초 제한은 미로와 같다. 전투에서 적에게 맞으면 현재 남은 시간에서 추가로 0.5초를 차감하며, 차감 후 시간이 0 이하이면 즉시 게임오버가 된다.
