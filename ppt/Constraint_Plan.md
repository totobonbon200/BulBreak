# 임시 제약 전환

## 최신 적용 기준
- 일반 진행은 모드에 맞는 후보 하나를 적용한다. 미로·전투 공통 후보 `고양이다아아아아`는 해당 제약의 활성 구간에만 시야를 가리는 효과를 적용한다.
- 전환 안내는 1초 동안 플레이 영역 중앙에 제목만 표시한다. 아래의 누적 규칙과 취득 위치별 안내 배치는 이전 기획이다.

- 첫 미로 → 전투는 생략하고 첫 전투 → 미로부터 목적지 종류의 제약을 안내한다.
- 안내는 1초이며 일반 타이머와 게임 진행을 멈춘 뒤 목적지에 진입한다.
- 그림은 미로 2행 2열~4행 3열 자리를 비운다. 제목은 2행 4열, 내용은 3행 4열에 표시한다.
- [미로] 도착 화면 확인, [전투] 임시 제약을 각 하나 준비하고 오른쪽 패널에 해당 모드의 활성 제약을 표시한다.
- 전용 게임오버 조건은 미정이므로 효과 없는 이번 제약에는 판정을 추가하지 않는다.

## 누적 제약 구조 — 최신 기획
- 제약은 새 제약을 얻을 때 기존 제약을 유지하면서 스택형으로 누적 적용한다.
- 활성 제약은 Python의 set으로 구현하며, 서로 다른 제약을 함께 보유하고 동일한 제약은 중복 저장하지 않는다.
- [미로] 도착 화면 확인: 다음 미로로 갈 도착점에서 maze 시트 1행 4열을 플레이 영역에 표시하고, 새 방향키 한 번으로 이동 없이 다음 미로로 전환한다. 미로 → 전투에는 적용하지 않는다.
- 도착 화면 확인은 해당 제약이 활성화된 경우에만 적용하며, 비활성 상태에서는 기존 자동 전환을 사용한다.
- set 기반 누적 관리와 도착 화면의 제약 조건 연결을 구현했다. 첫 전투 복귀 안내 종료 시 미로 제약을 얻으며, 이후 전환에서도 유지한다. 새 게임·재시작은 제약을 초기화한다.
