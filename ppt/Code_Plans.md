# Python 파일별 계획

- 각 `.py` 파일 상단에 사용자가 작성한 `#` 계획을 모아 관리하는 문서다.
- 구현 여부와 앞으로의 계획을 구분하며, 주석에 없는 역할이나 기능은 임의로 추가하지 않는다.
- 기능별 구현·수정 후 확인하고 작은 단위로 커밋한다. 자세한 커밋 규칙은 [AI_Planner.md](AI_Planner.md)의 작업 및 커밋 규칙을 따른다.

## 현재 확인 상태

현재 저장된 파일에는 사용자가 설명한 상단 계획 주석이 없어 원문 확인을 기다리고 있다. 아래 목록은 파일 확인 결과이며 구현 계획을 대신하지 않는다.

| 파일 | 저장된 상단 계획 주석 |
| --- | --- |
| `BulBreak.py` | 계획 주석 없음. 실행 방법을 적은 문서 문자열만 있음 |
| `codes/main.py` | 빈 파일 |
| `codes/game_framework.py` | 빈 파일 |
| `codes/maze.py` | 계획 주석 없음. 미로 좌표 기준을 적은 문서 문자열만 있음 |
| `codes/character.py` | 계획 주석 없음. 플레이어 상태와 애니메이션 설명 문서 문자열만 있음 |
| `codes/battle.py` | 빈 파일 |
| `codes/enemy.py` | 빈 파일 |
| `codes/gameover.py` | 빈 파일 |

파일 저장 후 상단 주석을 다시 읽어 파일별 계획과 기능별 커밋 단위로 정리한다.
