# BulBreak

BulBreak(벌브레이크)는 빠른 미로 탈출과 실시간 전투를 번갈아 진행하는 게임 프로젝트입니다.

- 미로는 n×n 크기로 무작위 생성되며, 각 미로를 최대 5초 안에 탈출하는 방식입니다.
- 벽을 향해 방향키를 두 번 누르면 벽을 통로로 바꿀 수 있습니다.
- 전투는 약 15~20초 동안 적의 패턴을 피하며 공격하는 방식입니다.
- 주인공은 왼쪽→오른쪽 또는 오른쪽→왼쪽 순서의 입력으로 공격합니다.
- 적은 플레이어의 조작에 따라 행동하며, 공격 패턴은 큐로 관리하도록 설계되었습니다.
- 진행에 따라 벽 파괴 제한, 적 패턴 표시 제한 등 다양한 제약을 추가할 계획입니다.
- 빠른 템포와 조작 숙련도의 재미를 목표로 합니다.
